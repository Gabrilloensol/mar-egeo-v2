# Odisea del Egeo — Mar Egeo V2

Edición web premium9. Aventura educativa, santuario y quince esculturas.

## Publicación

Vercel: importar este repositorio; el archivo vercel.json selecciona public como salida estática, sin instalación ni servidor Node. GitHub Pages: workflow incluido con publicación de public.

## Privacidad y alcance

Partidas en almacenamiento local. Sin recopilación de datos ni backend de aula. El servidor del paquete Windows no se publica. Exportar e importar desde Opciones para trasladar una aventura entre direcciones. La colección del santuario es compartida y su informe no es una copia importable.

## Validación

Ejecutar npm run check. La edición local pasó 74 pruebas técnicas y 18 bloques DOM. No equivale a aprobación visual en navegador/móvil ni pilotaje.

Créditos en public/creditos.html y en la ficha de cada escultura. Los recursos externos mantienen sus licencias; no se aplica una licencia global que las sustituya.
